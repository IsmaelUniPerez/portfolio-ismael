## 🚀 Cómo desplegar en plataforma gratuita:

### Opción 1: GitHub Pages (RECOMENDADO)

1. **Subir a GitHub:**
   - Crea una nueva repositorio en GitHub
   - Sube todos los archivos del `.portfolio`

2. **Activar GitHub Pages:**
   - Ve a Settings → Pages
   - En "Source", selecciona `/main` o `/master`
   - Guarda y espera 1-2 minutos

3. **Tu sitio estará disponible en:**
   `https://tu-usuario.github.io/portfolio/`

### Opción 2: Netlify (MÁS RÁPIDO)

1. Ve a [netlify.com](https://www.netlify.com/)
2. Arrastra la carpeta `.portfolio` directamente al área de drag & drop
3. ¡Listo! En segundos tendrás tu sitio en:
   `https://tu-sitio-nombre.netlify.app/`

### Opción 3: Vercel

1. Ve a [vercel.com](https://vercel.com/)
2. Conecta tu repositorio de GitHub
3. Despliega automáticamente

## 📸 Imágenes necesarias:

Necesitas 5 imágenes en la carpeta `assets/`:

1. **panzerdrifter.jpg** - Screenshot del juego Panzerdrifter (1920x1080 recomendado)
2. **mentirosos.jpg** - Portada de Mentirosos (1920x1080)
3. **teenysquids.jpg** - Menú principal Teeny Tiny Squids (1920x1080)
4. **barespacial.jpg** - Interior Bar Espacial (1920x1080)
5. **foto-israel.jpg** - Tu foto personal (recomendado: 600x800px)

**Tip:** Las imágenes se ven mejor con formato JPG o WebP, máx 500KB cada una para carga rápida.

## 🎨 Personalización rápida:

- **Cambiar email:** Busca línea 207 en `index.html`
- **Cambiar colores:** Edita las variables en `styles.css` (línea 8)
- **Añadir más proyectos:** Copia un bloque `<div class="slide">...</div>` y actualiza índice

## 📱 Responsive:

El sitio se adapta automáticamente a móviles, tablets y desktop.
